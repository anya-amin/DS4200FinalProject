Project Overview

The goal of this project is to explore current Airbnb listings in Boston, Massachusetts to analyze how property and host traits can affect nightly rental prices. This topic is important as Airbnb has become an extremely popular company in the real estate industry. It is a major part of the short-term housing market, especially in cities with tourism populations like Boston. Factors such as room type, location, number of reviews, amenities, etc., can be analyzed to display which features strongly predict listing prices. In the end, the results can be useful to hosts and travelers interested in understanding local market dynamics shaped by short-term rentals. The tasks included were to use different visualizations in order to portray this information and make some inferences. These visualizations include histograms, boxplots, scatter plots, heatmaps, and maps, each designed to highlight a different aspect of the data. Interactivity is incorporated through features like dropdown filters, interval selections, and hover tooltips, enabling users to filter, zoom, and drill down into specific insights. Explore more of the final project on this webpage!

Key Question: Which factors have the greatest impact on Airbnb listing prices in Boston, and which factors have minimal influence?

Data Introduction

The dataset used is derived from InsideAirbnb, an open data source, which provides detailed public data on Airbnb listings in major cities. The Boston dataset has 4560 listings and 23 features describing each property and host. The many features include room type, neighborhood, price and many others. The Airbnb dataset is a good fit for studying how different factors affect the price of listings in Boston as it includes insightful details about each Airbnb and host. In the end, after the dataset was filtered and cleaned, it included 16 of the most relevant attributes that was wanted for this project. 3642 data points were kept after removing any data points that were incomplete or had missing values.
